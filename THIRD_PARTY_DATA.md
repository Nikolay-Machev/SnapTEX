# Third-party data

## Google Research MathWriting 2024

- Project: https://github.com/google-research/google-research/tree/master/mathwriting
- Archive: https://storage.googleapis.com/mathwriting_data/mathwriting-2024.tgz
- Paper: https://arxiv.org/abs/2404.10690
- Authors: Philippe Gervais, Anastasiia Fadeeva, and Andrii Maksai
- Dataset content license: CC BY-NC-SA 4.0, according to the archive README
- Wikipedia-derived LaTeX labels: CC BY-SA 4.0, according to the archive README

SnapTEX's preparation script selects only records marked human-written and preserves source, split, sample identifier, and license metadata in every generated manifest row. The source archive and derived training files are not redistributed in this repository.

The dataset's noncommercial and share-alike terms make the initial SnapTEX fine-tune a research prototype. Do not use or distribute derived weights commercially without confirming that the intended use and distribution comply with all applicable licenses.
